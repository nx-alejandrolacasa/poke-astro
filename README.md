# Pokémon Pokédex

Browse every Pokémon by type and generation, with stats, abilities, evolutions and type matchups. Available in English and Spanish, with dark mode.

Built with [Astro](https://astro.build), [React](https://react.dev) and [Tailwind CSS](https://tailwindcss.com). Data comes from [PokéAPI](https://pokeapi.co).

## Develop

Requires Node.js 22.23.4 or newer.

```bash
npm install
npm run dev   # http://localhost:4321
```
